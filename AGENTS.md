# Agency Agents usage

Use the custom agents installed in `~/.codex/agents` as specialist reviewers for substantial work in this repository. Choose only roles that match the task, give them a concrete bounded assignment, and reconcile their findings against the repository code and tests. Project instructions and verified evidence take precedence over persona guidance.

Default project roles:

- Frontend behavior, design, accessibility, or speed: `Frontend Developer`, `UI Designer`, `UI Finish-Gate Reviewer`, `Accessibility Auditor`, and `Performance Benchmarker` as needed.
- Backend APIs, deployment, and reliability: `Backend Architect`, `Software Architect`, `SRE (Site Reliability Engineer)`, and `DevOps Automator` as needed.
- PostgreSQL schema, queries, retention, or egress: `Database Optimizer` and `Database Reliability Engineer`.
- Football analysis, data pipelines, and evaluation: `AI Engineer`, `Data Engineer`, `Statistician`, and `Reality Checker` as needed.
- Release readiness: `Code Reviewer`, `API Tester`, and `Evidence Collector`; use `Application Security Engineer`, `Secrets & Credential Hygiene Engineer`, or `AI-Generated Code Security Auditor` according to the risk.

Do not delegate trivial edits. For cross-cutting or high-impact changes, request an independent specialist review before declaring the work complete.
